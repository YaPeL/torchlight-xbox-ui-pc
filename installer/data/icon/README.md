# The installer's icon

A photo of the repository owner's own cat, made pixel art by the owner with ChatGPT (2026-10-24).
It is not from the game. The owner gave it under the repository's licence, the GNU GPL version 3
(`LICENSE`).

- `x360ui-install.ico`: the Windows executable's icon, 16 to 256 pixels (`src/x360ui-install.rc`).
- `x360ui-install-64.png`: the wizard's window icon, built into the executable (`CMakeLists.txt`).
- `x360ui-install.png`: the AppImage's icon, 256 pixels (`packaging/linux/make_appimage.sh`).

All three were scaled from the owner's 1254-pixel original: cropped to the cat, centred on a
transparent square, Lanczos.
